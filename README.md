# Mycel Releases

Official release builds of Mycel - DTN Mesh Messenger for Android.

## Installation

1. Download the latest APK from [Releases](../../releases)
2. Enable "Install from unknown sources" in Android settings
3. Install the APK

## Automatic Updates

Use [Obtainium](https://github.com/ImranR98/Obtainium) for automatic update notifications.

## Verification

Each release includes a SHA-256 checksum file. Verify your download:

```bash
sha256sum Mycel-*.apk
```
